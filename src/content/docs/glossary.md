Quick reference. Each entry links to the chapter that owns the full rule. Exact Practice numbers live on the live sheet, not in chat.

Default action die is **d8**. A **Mark** is any face of **5 or higher**.

----------

## Dice

| Term | Definition |
|------|------------|
| **Advantage / Disadvantage** | Judge who has the edge instead of stacking modifiers; upgrade or downgrade die tier (**d6** ↔ **d8** ↔ **d12**). Safe default **d8**. → [Marks & Tiers](/marks-and-tiers/#advantage-and-disadvantage) |
| **Die tier** | Which action die the pool uses: **d6** (harder), **d8** (ordinary default), or **d12** (easier). Set by Advantage / Disadvantage — not by Skill rating. → [Marks & Tiers](/marks-and-tiers/) |
| **Mark (of Success)** | A die showing 5+. → [Marks & Tiers](/marks-and-tiers/#marks-of-success) |
| **Omen die** | **d20** on every roll; Consequences and Tide input. → [Omens](/omens/#the-omen-die-and-consequences) |
| **Consequence** | Side event from the Omen die; must not rewrite the primary roll outcome. → [Omens](/omens/#the-omen-die-and-consequences) |
| **Opposed roll** | Contested action; compare Marks difference via reply chain. → [Tide](/tide/#situational-dice-resolution) |
| **Primitive action** | Foundation-only pool (no Skill). → [Marks & Tiers](/marks-and-tiers/#the-makeup-of-the-dice-pool) |
| **Tide** | Shared tracker for multi-party contests. Three sizes: Tiny skirmish, Small skirmish, Battle. → [Tide](/tide/) |

## Potential

| Term | Definition |
|------|------------|
| **Foundation** | One of nine inborn ratings (1–3 typical). → [Foundations](/foundations/) |
| **Strength** | Physical Foundation: raw power. Part of Echo capacity (with Dexterity, take the higher). → [Foundations](/foundations/) |
| **Dexterity** | Physical Foundation: speed, precision, balance. Part of Echo capacity (with Strength, take the higher). → [Foundations](/foundations/) |
| **Constitution** | Physical Foundation: endurance and hardiness. Part of Exertion maximum. → [Foundations](/foundations/) |
| **Intellect** | Mental Foundation: reasoning and learning. Part of Echo capacity. → [Foundations](/foundations/) |
| **Perception** | Mental Foundation: awareness and observation. → [Foundations](/foundations/) |
| **Resolve** | Mental Foundation: willpower. Part of Exertion max. → [Foundations](/foundations/) |
| **Charisma** | Social Foundation: presence and force of personality. → [Foundations](/foundations/) |
| **Guile** | Social Foundation: cunning and deception. → [Foundations](/foundations/) |
| **Authority** | Social Foundation: natural command, gravitas. Part of Echo capacity. → [Foundations](/foundations/) |
| **Skill** | Rated 0–3 practiced ability under an Archetype. → [Skills](/skills/) |
| **Archetype** | One of six named groups of related Skills (Warrior, Wayfarer, Artisan, Mother, Sage, Trickster). Not a class. → [Skills](/skills/) |
| **Practice** | Progress toward Skill level-up. Exact numbers live on the live sheet; adapters do not print them. → [Skills](/skills/#improvement) |
| **Trait** | Binary custom feature; positive or negative by context. → [Traits](/traits/) |
| **Exertion** | Spendable pool for extra dice; also fatigue/hunger/thirst ledger. Max = Resolve + Constitution + Charisma. → [Exertion](/exertion/) |

## Continuity

| Term | Definition |
|------|------------|
| **Community** | The shared protagonist (tribe, village, house…). If destroyed, the campaign ends. → [Introduction](/introduction/) |
| **Echo** | A carried deed or concern with weight 1–3. → [Echoes](/echoes/) |
| **Capacity (Echo)** | max(Strength, Dexterity) + Intellect + Authority; max total Echo weight without penalty. → [Echoes](/echoes/#weight-and-capacity) |
| **Decadence** | Carrying zero Echoes; –1 die on every roll. → [Echoes](/echoes/#weight-and-capacity) |
| **Pivotal Echo** | Weight 3; can move a Fortune and become a Myth. → [Echoes](/echoes/) |
| **Invocation** | Spending a second Exertion die when an Echo matches the roll. → [Echoes](/echoes/#invocation) |
| **Foundation Myth** | One of up to three active resolved Pivotal Echoes with community-wide effects. → [Echoes](/echoes/#foundation-myths) |
| **Fortune** | One of five soft community measures (0–3). Ambient context for the whole community. → [Echoes](/echoes/#fortunes) |
| **Vitality** | Fortune: people, health, capacity to absorb loss. → [Echoes](/echoes/#fortunes) |
| **Cohesion** | Fortune: trust and willingness to act together. → [Echoes](/echoes/#fortunes) |
| **Surplus** | Fortune: material buffer. → [Echoes](/echoes/#fortunes) |
| **Standing** (Fortune) | External reputation of the *community*. → [Echoes](/echoes/#fortunes) |
| **Tradition** | Fortune: shared memory and self-belief. → [Echoes](/echoes/#fortunes) |
| **Harm** | Damage on a Foundation’s named track (0–3). → [Harm](/harm/) |
| **Dying** | Any Harm track at 3; every roll costs Exertion; death at Exertion 0. Healing is not a superpower. → [Harm](/harm/#dying) |
| **Protection ratio** | ÷1 / ÷2 / ÷3 from armour or Reputation when converting margins to Harm. → [Harm](/harm/#inflicting-harm) |
| **Hierarchy** | Axis of standing (Arms, Faith, Coin, Blood by default). → [Hierarchies](/hierarchies/) |
| **Honoured / Trusted / Acknowledged / Outcast** | Hierarchy tiers. → [Hierarchies](/hierarchies/#tiers) |
| **Outsider** | Not yet of the community; sits apart on the Diagram. → [Hierarchies](/hierarchies/#tiers) |
| **Ruler** | Single shared top seat above all Hierarchies. → [Hierarchies](/hierarchies/#tiers) |
| **Reputation** | Relative Hierarchy position; social/mental armour analogue. → [Hierarchies](/hierarchies/#reputation) |
| **Diagram** | Shared Hierarchy record of tracked characters. → [Hierarchies](/hierarchies/#the-hierarchy-diagram) |
| **Legacy** | Echo claimed by a successor character after death. No free rank. → [Hierarchies](/hierarchies/#legacies) |
