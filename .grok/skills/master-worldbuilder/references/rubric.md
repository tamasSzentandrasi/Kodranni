# Review rubric

Score each row: **hard** (Character Creation bar), **soft** (present but thin), **missing**, **over** (too much, cut). Quote the chapter. Do not invent content to fill a miss. When theory warrants a change, attach a `Q-…` id from `quotations.md`.

Required rows must reach **hard** before the chapter is finished. Optional rows may stay soft.

## Seeds and signal

| ID | Test | Required |
|----|------|----------|
| S1 | Seed rule is teachable: place name, community, real pressure already true, named people already pulling. A vague, horror-list, two-rights slogan, or predicted-ending seed can be rejected in one sentence. | yes |
| S2 | Worked seeds on the page each pass S1. Historical / semi / invented stay distinct. | yes |
| S3 | Interest signal stays tight: ranked list + three constraints. Players are not given a world. | yes |
| S4 | Seed-writing has rejection rules as sharp as “weak ties are rejected.” | yes |

Failure: “river country”; a list of calamities with no choice; invented misery for effect; a seed that is a plot (“then they will besiege…”).

## Nine steps

| ID | Step | Hard gate | Named failure | Required |
|----|------|-----------|---------------|----------|
| W1 | Spectrum | Spectrum written on the first line of notes and kept. | Mixing historical constraint with invented-away cost of living. | yes |
| W2 | How they live | Hard season, food, shelter, who settles quarrels, where people are when not “on a job.” | Hollow place; conquerors who already farm like the dead. | yes |
| W3 | What must not fail | Five to eight countable things. Each can drive a session. | Abstract “hope” / “culture”; a throne as backstory to recite. | yes |
| W4 | Strain now | One present-tense sentence per item: who presses, what cannot wait, what happens if nobody acts. | Adjectives; a sentence that could sit on any map. | yes |
| W5 | Who holds it | Few people/houses with wants, unforgivables, and a default if left alone. | Cast list; ranks without leverage; no face on a strain. | yes |
| W6 | Leave blanks | Standing, trust, and hierarchy are discovered in play. Private notes stay off the table. | Session-zero lore dump of who sits where. | yes |
| W7 | What they can see | Three or four marks anyone can point at. Secrets are facts, not a delivery script. | Lecture; marks that never recur; fresco-of-the-week. | yes |
| W8 | Themes and threads | Each thread is a situation that worsens if ignored. Participation is the table’s. | Required side quests; themes announced as slogans. | yes |
| W9 | Fortunes | Vitality, Cohesion, Surplus, Standing, Tradition derived from the facts above, soft 0–3. Comfortable-after-conquest fails the check. | Epic numbers; Fortunes as vibe; no store-when-created. | yes |

W2 and W4 are the load-bearing gates. If either is soft, stop scoring atmosphere.

## Evenness

| ID | Test | Required |
|----|------|----------|
| E1 | Method proven on **two existing seeds** (Aspalath plus one historical already on the page). Not a new seed. | yes |
| E2 | Each step’s best-practice is one failure + one gate + one next action. No doubled lecture. | yes |
| E3 | Voice matches Character Creation: procedural, short, grim, no new gags. | yes |
| E4 | Cross-links: Fortunes → Echoes, blanks → Hierarchies, constraints → Introduction. Anchors land on visible headings. | yes |
| E5 | Widgets still teach. JS contains no scene prose. | yes |

## Anti-patterns (any hit is a fail)

- Lore dump (gazetteer, standing list, culture essay) on the player-facing page.
- Plot-prep: “the players will then…”, forked scene sequences, pre-solved social map.
- Misery tourism or theatrical grimdark.
- Magic, races, cosmology, Wrede-style questionnaires.
- Conquerors handed the dead people’s craft.
- New humour, `{#slug}`, new ornament class.
- Invented seed or invented Aspalath facts without an author ask.
