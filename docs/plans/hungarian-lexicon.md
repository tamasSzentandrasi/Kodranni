# Hungarian Guidebook lexicon

Locked 2026-08-22 (alignment + author review). Translation authority for `src/content/docs/hu/`. Do not drift.

Voice: **tegezés** only (`te` / `ti`). No magázás, no önözés. Grim, short, procedural. Named mechanics bold on first use. Ritual titles: **A Megmérettetés**, **A Kívánás**. Quotes: `*„….”*`. Place names and *Kodranni* stay. First-use gloss **magyar (English)** for sheet/bot words. Running text uses Magyar. Live sheet labels stay English.

Automation, Discord, Fluxer, campaign-ui stay English.

## Humour (do not add more)

- *“It's Fiiiine” — a Storyteller describing something definitely not fine* → **„Ó, hát minden renden leeesz…” — egy mesélő, egy olyan helyzetről, ami semmiképp sem lesz rendben**
- *“Don't worry. I'll kill you eventually.”* → **„Ne izgulj. Úgyis megöllek előbb-utóbb.”**
